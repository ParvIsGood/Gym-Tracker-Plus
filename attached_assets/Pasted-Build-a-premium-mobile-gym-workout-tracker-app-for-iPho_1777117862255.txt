Build a premium mobile gym workout tracker app for iPhone and Android with a modern dark theme, smooth animations, and a motivating fitness vibe. The app should feel addictive, satisfying, and professional—like opening a premium fitness app every day. Every tap should feel smooth, every workout log should feel rewarding, and progress should feel exciting.

CORE USER EXPERIENCE
- Clean and focused UI with no clutter
- Premium dark mode
- Smooth transitions
- Fast logging flow
- Motivating charts and streaks
- Haptic feedback if supported

WEEKLY WORKOUT PLANNER
Default split:
Monday - Chest Day
Tuesday - Back Day
Wednesday - Leg Day
Thursday - Shoulder Day
Friday - Arms Day
Saturday - Full Body / Weak Point Day
Sunday - Rest Day
Allow full customization.

EXERCISES BY DAY
Chest: Bench Press, Incline Press, Chest Fly, Pushups, Pec Deck
Back: Lat Pulldown, Seated Row, Deadlift, Pull-ups, Cable Row
Legs: Squats, Leg Press, Lunges, Leg Extension, Hamstring Curl, Calf Raise
Shoulders: Shoulder Press, Lateral Raise, Rear Delt Fly, Front Raise
Arms: Bicep Curl, Hammer Curl, Tricep Pushdown, Skull Crushers

WORKOUT LOGGING SYSTEM
When user taps Start Workout:
- Show exercise cards one by one
- User can choose exercises for the day
- Add custom exercises

Each exercise card includes:
- Weight slider (0kg to 300kg)
- Reps slider (1 to 30)
- Sets slider (1 to 10)
- Difficulty slider: Easy / Moderate / Hard / Failure
- Notes field
- Add Set button
- Complete Exercise button
- Skip button

SMART EXERCISE SELECTION
Ask available equipment:
- Full gym
- Machines only
- Dumbbells only
- Home workout
Recommend matching exercises automatically.

CORRECT FORM GUIDE
Every exercise has How To Perform Correctly section.
Examples:
Bench Press:
- Feet planted
- Back tight
- Controlled lowering
- Press upward strongly

Squat:
- Feet shoulder width
- Chest up
- Knees track toes
- Drive through heels
